INTEGRASI CLOUD SPREADSHEET

Ekspor ke Google Sheets

⚡ Tercepat & Direkomendasikan 1. Salin Otomatis & Buka Google Sheets Baru

Menyalin seluruh tabel transaksi, jadwal tagihan, & ringkasan planner dalam format kolom Google Sheets, lalu membuka sheets.new. Cukup tekan Ctrl+V / Cmd+V di sel A1!

2. Unduh File Format Google Sheets (.CSV)

Unduh file yang sudah diformat untuk langsung dibuka melalui menu File → Impor → Upload di Google Sheets atau Google Drive.

3. Sinkronisasi Webhook Google Apps Script (Opsional)

Masukkan URL Web App Google Apps Script milikmu untuk mengirim data langsung ke lembar Google Sheets secara otomatis.
